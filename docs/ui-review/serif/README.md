## Промени

- `globals.css`, `_app.tsx`, `Input`, `Button`, `SectionCard`: графитни семантични повърхности, mint акценти, Lora за serif заглавия/CTA и Inter за текст/суми. Шрифтовете са локални чрез `next/font/local`, с OFL лицензи; проверено е българското покритие на Lora. Системната светла тема е запазена.
- `TripsOverview`, `TripCard`, `Navbar`, `MobileNavigation`: реални броячи, компактни карти и разрешени действия; съществуващите маршрути, menu, profile и invitation flags са запазени.
- `TripHeader`, `ExpensesTable`: графитна карта с общата сума и пълни имена на семействата; вторичните действия са под „Още“. Локално „Добави“, описание/платец/сума/дата, подробности и редакция/изтриване при разгъване. Използва се неутрална receipt икона, без измисляне на категории.
- `AddExpenseForm`: една повърхност, отчетлива сума, три ясни режима, отделен платец, текущият преглед на дяловете и погасяване. Dock-ът се скрива при отворена форма/редакция, модал или намален visual viewport за клавиатура.
- `AuthWelcome`, login/register/recovery: орбита с локален компас, капсулни tabs, полета с икони/autocomplete, показване/скриване на паролата и CTA. Tabs запазват валидния вътрешен redirect.
- Grid колоните, редовете по семейства и финансовото резюме пренасят дълги имена и големи суми. Управляващите икони на семейство се показват само при подаден разрешен handler и имат зони 44×44 px.

Не са променени финансови формули, историческо разпределяне, Firebase схеми/правила, членства, API или feature flags.

## Проверки

- Lint, TypeScript, production build с `--webpack`, `git diff --check` — успешни.
- `npm test`: **20/20** теста. Наличните интеграционни тестове срещу demo Firestore/Auth: **3/3**.
- **48** browser проверки: четири екрана × 320/375/390/430/768/1280 px × светла/тъмна тема; без преливане или JS page errors. [Метрики](metrics.json).
- Действителни UI/API записи: покупка от 30 € само за друго семейство с дял на платеца 0; последващо погасяване без повторно увеличение на покупките; редакция към избрани получатели; създаване/архивиране/възстановяване/потвърдено изтриване и отказ. Проверени са собственик, участник и Admin claim. [Резултати](flows.json).
- Клавиатура, focus, redirect, recovery маршрути, reduced motion, dock при форма/модал/симулирана клавиатура, големи суми и 200% текстов stress — успешни. [Метрики](stress.json), [снимка](long-names-large-text.png).
- Контраст на активни текстове и placeholder-и в седем екрана и двете теми: минимум **4.82:1** в измерените двойки. [Резултати](contrast.json).

Снимките и browser проверките използват **реалното Next.js приложение**, реален Firebase Auth вход, Firestore rules и `/api/community`, насочени само към локален `demo-tripsplitly` емулатор. Имената, датите и сумите са изолирани тестови данни. Next dev индикаторът е скрит само при заснемането. Поканите са активни в demo средата по съществуващата emulator настройка; продукционният rollout остава непроменен. Permission-denied съобщенията в отрицателните rules тестове са очаквани.

Физически iOS/Android, реална софтуерна клавиатура и safe-area на устройство остават за мобилния преглед. Увеличеният текст е CSS stress, не реален browser zoom.

## Умишлено пропуснато

Google/Apple вход, категории, бутони +сума, дневни бюджети/проценти, „Отчети“, начини на плащане, примерни аватари/души/статистики/дата на уреждане, „Еврозона“, „Защитена сесия“ и „Оптимизирано“. Не е добавян нов shortcut „Погаси“; текущият изрично потвърждаван запис през „Пито платено“ е запазен. Архивирано не се представя като финансово уредено.
