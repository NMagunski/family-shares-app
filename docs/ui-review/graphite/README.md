## Какво е променено

Общи семантични цветове за двете системни теми, sans-serif заглавия, по-компактна лента с локалния компас, кръгли CTA, карти с отделни семантични контроли за отваряне и разгъване. „Общ преглед“ използва единствено наличните броячи. Мобилният dock отваря същия NewTripWizard; в пътуване води до съществуващите секции за разходи и баланс. Скрива се при модал и при намален visual viewport за клавиатура, има safe-area padding и активно състояние.

Общите токени и компоненти се прилагат към останалите екрани; запазени са компактната история на разходите и бялата карта с действителните разплащания. Не са променени бизнес логика, заявки, права, feature flags, финансови формули, исторически записи или Firebase правила.

Не са добавяни примерни финансови баланси, суми, аватари, брой „души“, дата на уреждане или „Отчети“. За тях липсват налични надеждни данни/маршрут. Архивираното пътуване не се представя като финансово уредено. Профилният shortcut се показва само при съществуващия feature flag.

## Шрифтове

Inter и Plus Jakarta Sans са локални оригинални variable TTF файлове от [Google Fonts](https://github.com/google/fonts), с включени OFL лицензи. Зареждането е чрез [next/font/local](https://nextjs.org/docs/pages/getting-started/fonts), без заявки към Google при отваряне или build. Plus Jakarta Sans се използва за поддържаните знаци в заглавията и сумите. Проверка на cmap потвърди, че този файл няма български букви; за тях fallback е Inter, който има пълното необходимо покритие.

## Проверки

- `npm run lint`, `npm run typecheck`, `npm test` — 19 теста, `npm run build -- --webpack`, `git diff --check`.
- Chromium/Playwright: 320, 375, 390, 430, 768, 1280 CSS px × светла/тъмна тема. Без хоризонтално преливане в списъка и екрана за разходи, включително голяма сума и дълги имена.
- Празен списък, много записи, loading/error, admin меню, собственик/участник, 200% текстов stress, reduced motion.
- Действителните React handlers за създаване, архивиране, възстановяване и отказ от изтриване; keyboard разгъване и Escape/focus за менюто; footer над dock след превъртане; anchor и aria-current за баланса.
- Измерен контраст на действителни текст/фон двойки в списък, разгънати действия, hover и NewTripWizard. Минимум 4.83:1 за проверените активни текстове. `#003824` върху `#10B981` е 5.20:1. Прозрачните фонове са композирани при измерването. Неактивните контроли са изключени от минималния контраст.
